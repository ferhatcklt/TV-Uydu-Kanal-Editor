🛰️ Televizyona USB ile Kanal Listesi Yükleme Kılavuzu

1

Dosyayı USB'ye Kopyalayın

Formatı ALi (.bin) seçin ve "USB İçin İndir" butonuna basın. İndirilen CHANNELLIST.bin dosyasını FAT32 formatlı USB belleğinizin ana dizinine kopyalayın.

⚠️

ÖNEMLİ: TV'de TKGS Modunu Kapatın

Menü ➔ Kurulum ➔ Türksat TKGS Ayarları ➔ TKGS Modu: KAPALI

TKGS açık kalırsa televizyon özel listenizi silip fabrika sırasına döner.

2

TV'ye Yükleme

Menü ➔ Kurulum ➔ Uydu Ayarları ➔ Uydu Kanal Tablosu ➔ "USB'den TV'ye Yükleme"

1

.sdx Dosyasını İndirin

Üstten Vestel / Regal / Toshiba (.sdx) formatını seçip indirin. Dosyayı FAT32 USB belleğin ana dizinine koyun.

2

Vestel TV'den Yükleme

Menü ➔ Ayarlar ➔ Uydu Ayarları ➔ Uydu Kanal Tablosu ➔ "USB'den TV'ye Yükleme"

İşlem tamamlanınca televizyonu kapatıp açın.

1

USB Kanal Listesi Aktarımı

Ayarlar ➔ Yayın ➔ Uzman Ayarları ➔ Kanal Listesi Aktarımı

Önce TV'nizden "USB'ye Ver" diyerek yedeğinizi alın, editörde düzenledikten sonra "USB'den Al" seçeneği ile geri yükleyin.

1

LG webOS Kanal Kopyalama

Ayarlar ➔ Kanallar ➔ Kanal Kopyalama (TV'den USB'ye / USB'den TV'ye)

Dosyanız GlobalClone00001.TLL adıyla aktarılacaktır.

1

Sony Bravia Program Listesi Transferi

Ayarlar ➔ Kanal Kurulumu ➔ Dijital Kurulum ➔ Teknik Ayarlar ➔ Program Listesi Aktarımı (İçe / Dışa Aktar)

Sony TV'lerde sdb.xml dosyası transfer edilir.

1

M3U Oynatma Listesi

M3U formatını indirerek VLC Media Player, Smart IPTV, TiviMate, SS IPTV veya Kodi gibi tüm akıllı televizyon ve TV Box uygulamalarında anında kullanabilirsiniz.
